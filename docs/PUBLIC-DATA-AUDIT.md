- 首次发布为独立源码快照：本地对应 Git 仓库只有 1 个可达提交，文件数为 907；此前已核对远端文件列表与发布清单一致。

- 从本机实际配置、Meting Cookie／加密密钥／Token 等文件中抽取 11 个长度足够的配置或凭据值，仅在内存中与发布源码快照逐文件比较，没有命中；本记录不包含这些值。这不等于对所有可能格式、加密前明文或二进制嵌入内容作出完整证明。
- `server/friendsSources.js` 将扫码获取的 Cookie 交给 Meting 管理接口；Meting 账号数据属于部署时挂载的数据目录，没有写入发布源码。
- `server/friendsLibrary.js` 将个人歌单写入 Redis 的 `openmusic:friends-library:v1:*`；`server/friendsListening.js` 将历史与统计写入 `openmusic:friends-listening:v1:*`。只读检查确认这些运行时键仍存在，没有导出或上传其内容。
- 本机已登录音乐账号、已导入歌单及听歌历史没有被退出、删除或迁移。排除发布数据与清空本机数据是两个不同动作，本次只做前者。

全新部署应使用自己的空数据目录、Redis 和音乐平台登录；如果仍指向原有 Redis 或 Meting，网页会继续显示原有记录，这不表示记录被打包进源码。
